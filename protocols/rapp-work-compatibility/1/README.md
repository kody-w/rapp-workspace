# RAPP Work Compatibility/1

Optional compatibility, mutation and learned-handshake application profile
above unchanged RAPP Workspace/1 and canonical RAPP/1.

The profile validates inert Compatibility/Exhaust records, double-hotload
receipts, deterministic static program generation, artifact bundles,
bidirectional repository lineage, mutation offers, bounded N-Lens search and
meta-evolution evidence. It does not grant authority or run a production
Brainstem.

The first fixture binds the SoftwareCo V-team Hive/MicroSOL handshake without
including live private source Frames.

```bash
python3 -B protocols/rapp-work-compatibility/1/reference/schema_source.py --check
python3 -B protocols/rapp-work-compatibility/1/reference/pins.py
PYTHONPATH=protocols/rapp-work-compatibility/1/reference \
  python3 -B -m unittest discover \
  -s protocols/rapp-work-compatibility/1/tests -v
python3 -B protocols/rapp-work-compatibility/1/reference/conformance.py \
  --rapp1-path "<EXPLICIT_RAPP1_CHECKOUT>"
```

MicroSOL retains only its concrete live subscription profile. The generic
profile ID and schemas are owned here to avoid competing product contracts.
