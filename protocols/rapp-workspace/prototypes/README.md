# RAPP Workspace prototypes

Everything in this directory predates the core `rapp-workspace/1` authority.
It is preserved as inert research, migration evidence and exact historical
bytes. Nothing here is selected by the core validator or imported by the core
CLI.

- [`grail-1.0/`](grail-1.0/) is the complete previously published candidate,
  preserved without changing its bytes.
- [`published/`](published/) contains byte-pinned 1.1 and 2.0 snapshots plus
  the record that no separate published 1.0 specification was found.
- [`legacy-manager/`](legacy-manager/) contains the old pointer-manager
  prototype formerly exposed as a root tool.

[`index.json`](index.json) pins the candidate archive and published prototype
catalog. Archived prototype test sources live under `tests/prototypes/`. They are
evidence from the prototype era, not a supported core acceptance suite.
