# Withdrawn, unqualified seed/lens experiments

This directory preserves the previous **unpublished** working draft and its
regressions as research evidence. It is NOT the first-Grail contract, an
accepted old `rapp-workspace/1.0` interpretation, or a safe authority controller.
Its historical working labels and claims are not active protocol identifiers.

The active unique specification is
[`rapp-workspace/grail-1.0`](../SPEC.md), branded **RAPP Workspace/1 Grail**.
Its validators and CLI do not import this directory. Experimental entry points
require `RAPP_ALLOW_UNQUALIFIED_EXPERIMENTS=1` and still grant no authority.
The separate experimental tests are regression evidence only, not first-Grail
release acceptance or proof that the red-team blockers were resolved here.

In particular, old in-graph adoption, incomplete assurance separation, native
rebinding/migration, correspondence-free merge/reattach and broad evolutionary
claims MUST NOT be deployed through this prototype. First Grail refuses those
unqualified capabilities instead of treating a previous green test as proof.
